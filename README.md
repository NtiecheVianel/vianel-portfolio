# Vianel TIAGUE NTIECHE — Portfolio

Personal portfolio and showcase for **Vianel TIAGUE NTIECHE**, UI/UX Designer & Web / Software Developer based in Lomé, Togo.

## Overview

- **UI/UX Design**: Wireframing, high-fidelity prototypes, and design systems built in Figma.
- **Web & Full-Stack Development**: Fast, accessible, mobile-first web applications, dashboards, and marketplace platforms.
- **Key Projects & Experiences**:
  - **Société Togolaise des Eaux (TdE)**: Complete website UI/UX redesign & dynamic statistics/graph generation platform with exportable reports.
  - **Onomamarket**: Scam-free peer-to-peer e-commerce marketplace platform.
  - **Asiatic International Corp**: Digital operations, visual campaign design, and remote virtual assistance.
  - **Lomé Business School**: 2nd Year Information Systems (President of the English Club).

## Tech Stack

- **Framework**: React 19, TanStack Start & TanStack Router
- **Styling**: Tailwind CSS v4, Lucide Icons, Poppins Typography
- **Design**: Figma, Prototyping, Design Systems
- **Back-End & DB**: PHP, SQL, Java, WordPress

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
